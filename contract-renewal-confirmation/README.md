# 契約更新 本人意思確認システム

グラビティ株式会社の社内管理ツール群「グラナビ」の新規モジュール。3ヶ月単位の契約更新前に、エンジニア本人へ「更新してよいか」の意思確認を行うプロセスの一部を自動化する。

## このプロジェクトが解決すること

現状、営業事務が対象者へ個別にメールを送り、返信を確認して、Excel台帳へ手動で記入している「本人意思確認」ステップを、システム化する。目的は次の2つ。

1. エビデンスを残すこと
2. 担当者依存（属人性）を減らすこと

前後の事務手続き（見積書送付・契約書作成・郵送等）は対象外。あくまで「本人に確認を取る」ステップのみが対象。

## ドキュメント

| ファイル | 内容 |
|---|---|
| `docs/requirements.md` | 業務要件（確定版、正本）。7回の第三者レビューを経て確定 |
| `docs/business-flow-diagram.svg` | 業務フロー図 |
| `docs/decisions-log.md` | 意思決定ログ。何を・なぜ決めたかの記録 |
| `CLAUDE.md` | Claude Code向けの作業ルール・技術的制約 |

## 構成

- `frontend/applicant.html` - 本人向け画面（モバイル、認証なし）
- `frontend/ops-console.html` - 営業事務向け画面（MSAL.js認証）
- `backend/` - AWS上のバックエンド（Lambda等、技術設計後に確定）
- `infra/` - インフラ定義（IaC、技術設計後に確定）

## セットアップ・デプロイ

技術設計確定後に記載する。
